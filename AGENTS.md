# IXXIMEOW repository scope

These instructions apply to every task performed in this repository.

## Hard scope boundary

- This repository is exclusively the IXXIMEOW engineering project.
- The only authorized repository target is `glowqiEU/ixximeow`.
- Do not read from, copy from, compare against, modify, commit to, or open pull requests against any GLOWQI product repository.
- In particular, `glowqiEU/inquiry-compass` is out of scope and must remain untouched.
- Do not import GLOWQI product concepts, research-pipeline architecture, UI, data, prompts, tests, branches, issues, or implementation details into IXXIMEOW.
- The shared `glowqiEU` owner name does not make the projects interchangeable.

## Conflict handling

If conversation history, memory, attachments, branch names, or task instructions appear to mix IXXIMEOW with GLOWQI:

1. Stop before making repository changes.
2. Keep `glowqiEU/ixximeow` as the active project.
3. Discard GLOWQI-specific context from the engineering task.
4. Ask the user only when the requested target still cannot be determined safely.

Repository evidence is authoritative for IXXIMEOW implementation decisions.
